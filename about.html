What this is

Airis OS is a personal, open-source project that runs entirely in your browser at jaxah.com. It is a desktop of small apps. You and an agent act on the same surface through the same set of actions, and every action, whoever took it, is written to one visible Trail (human, agent, app or system). It is not a bank, a shop or a sign-in page: it has no accounts and no sign-in.

What you get

  • Session: a blank chat with a live agent. You bring your own API key (OpenCode Go, OpenRouter, or any OpenAI-compatible endpoint you choose, including one on your own machine). The key is stored in this browser only.
  • Apps that run sandboxed: each app runs in an isolated iframe with no access to the desktop, your keys or other apps; anything privileged goes through the shell, which checks what the app is allowed to do.
  • Install records: an installed app is a record kept in your browser, code included. Store lets you install, remove, export everything as one JSON file and import it again.
  • The terminal floor: a plain text terminal underneath the desktop with scripted, local replies. It keeps working even if the rest fails; press the backtick key, or open /?terminal=1.
  • Small apps and experiments already installed: Lexfall (word game), To Do, Persona, House, Desk, Fuel Calc, LSB Lab, JEB Gallery and others.

About keys

You only need a key for Session. Other apps work without one. For OpenRouter and custom endpoints the browser talks to the provider directly. OpenCode Go does not accept direct browser calls, so this site relays those requests: your key passes through and is not logged or stored.

How it is built

One Cloudflare Worker serves static files from a public repository. There is no database and no server-side storage: the Worker has none, on purpose. The rules for the whole site are published as data in /airis.contract.json.
